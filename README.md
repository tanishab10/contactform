# Maincrafts – Java Full Stack Internship Task 2

## Project Overview

A contact form web application built using Spring Boot that stores submitted contact details in a database.

## Features

* Contact form with Name, Email, and Message fields
* Spring Boot backend
* Spring Data JPA for persistence
* POST endpoint to save contact submissions
* GET `/contacts` endpoint to retrieve saved records in JSON format

## Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* MySQL (if configured)
* HTML and CSS

## Run the Project

Run the Spring Boot application and open `http://localhost:8080/` in your browser.

To view saved contact records, visit `http://localhost:8080/contacts`.
